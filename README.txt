진주 야행 행사안내·신청 웹페이지 (데모)

파일 구성
- index.html : 메인 페이지 구조
- css/style.css : 디자인과 반응형 스타일
- js/main.js : 메뉴, 전체 일정 팝업, 전체 프로그램 팝업, 사전등록 폼
- assets/festival-poster.png : 사용자가 제공한 참고 포스터 이미지
- assets/palace.svg, lanterns.svg, culture.svg : 웹페이지에 삽입한 로컬 일러스트 이미지

사용 방법
1. 압축을 풉니다.
2. index.html 파일을 크롬 등 웹브라우저에서 엽니다.
3. 사전등록 버튼, 전체 일정 보기, 전체 프로그램 보기 버튼을 눌러 기능을 확인합니다.

참고
- 행사 날짜, 장소, 프로그램은 디자인 시연을 위한 가상 정보입니다.
- 사전등록은 화면 시연용이며 실제 서버로 전송/저장되지 않습니다.
- 실제 운영 전에는 공식 행사 정보, 개인정보 처리방침, 서버/API 연동을 설정해야 합니다.
- CSS와 JavaScript는 각각 별도 파일로 분리되어 있습니다.
